# The Houseplant Out-of-Office

A tiny Node program that writes the funniest out-of-office auto-reply a houseplant would send: a plant that has been out of water since March, so it delegates urgent matters to the cactus — who has seen things and will not help either — and `main.ts` writes that single 119-character line to `entry.txt` in the output directory.

## Run

```sh
node main.ts
```

It reads `MAKEFUN_OUTPUT_DIR` (default `/output`), creates the directory if needed, and writes `entry.txt`.
